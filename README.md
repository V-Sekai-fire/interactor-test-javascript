# interactor-test-javascript

A one-scene Godot project that runs an ECMAScript module as a node's script.

## What it is for

It checks that an engine built with an ECMAScript scripting module loads an `.mjs` script on a
node, calls its ready and per-frame callbacks, and reaches engine singletons from the script.

## Run

Open the project in an editor built with that scripting module and run its main scene.
